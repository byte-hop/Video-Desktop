# 影视窗 v0.1.26

Windows 桌面端影视聚合播放器(基于https://github.com/hgtuj5688/tvbox-desktop/ 二次开发)。
本版本不含任何影视源、直播源与推荐订阅——软件安装完自己添加配置源，内容全部来自你添加的第三方站点。

## 一、下载与播放

- 下载记录页（0.1.1）：侧栏新增入口，分「正在下载 / 下载完成」。显示分段进度、百分比、速度，可取消、打开所在文件夹、删除单条或清空。任务落盘到 data/downloads.json，最多同时下 2 条，其余排队。
- 断点续传（0.1.4）：退出或崩溃后重启，中断的任务自动重新排队接着下。HLS 记已完成分片 + 清单指纹，直链走 HTTP Range；服务器不认 Range 就退回从头下。失败 / 取消的任务可一键重试。
- 关窗收托盘（0.1.2）：点关闭不再退出，缩进托盘继续跑下载与播放；开着系统画中画时关窗视频照播。要真退出走托盘菜单「退出影视窗」。
- 历史续播（0.1.7）：从历史记录点进播放页会 seek 回上次位置，不再一进来就被 0 覆盖。
- 片源挂了自动换源（0.1.9）：点历史里的影片时，原源请求失败就按片名去其它已启用源找同一部，带上集数与进度自动切换。谁先返回同名结果就用谁，实测 3 秒完成（原来要等全部超时约 26 秒）。
- 本地播放（0.1.21）：选磁盘上的视频或直接拖进窗口就能播，不联网、不上传。最近 12 个文件记在本地，点一下接着看；切页时同样缩进右下角小窗继续放。

## 安装与首次启动

1. Windows 10 / 11 x64，解压到任意目录（别放进系统目录）。
2. 没有代码签名证书，首次运行会触发 SmartScreen：点「更多信息」→「仍要运行」。
3. 第一次打开先读使用声明，同意后进入主界面。
4. 进「影视源」页添加你自己的配置源（支持 A / B 两种 JSON 方言，URL 或本地文件均可），同步一次就有内容了。

## 已知限制

- 解析接口只做 HTTP 解析（type=1 / 2），type=0 的浏览器嗅探未做。
- 播放进度取决于源：直接给 m3u8 的源进度准确，只给分享页地址的源拿不到进度。
- 公开采集站随时可能失效，在「影视源」页点「测试」即可看出。
- 语言开关目前只翻「外壳」（侧栏导航、搜索占位、顶栏按钮、设置页分区标题、首启页），页面正文与使用声明仍是中文，后续逐页翻。
